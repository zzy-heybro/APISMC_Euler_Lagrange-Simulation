APISMC Simulation Code
Simulation code for "Adaptive Predefined-Time Fractional-Order Integral Sliding Mode Control for Euler-Lagrange Systems"

 Requirements
- MATLAB R2021b or later
- Fractional Calculus Toolbox (This is a replacement version that can still run without the fractional integration toolkit.)

How to Run
1.  Clone or download this repository
2.  Open MATLAB and set the repository folder as the working directory
3.  Run `main.m` to generate all simulation results

Notes
- All parameters are configured to match the values in Table 2 of the manuscript
- Password-free access is provided exclusively for the review phase
